## 🚀 Quick Start

### Prerequisites

- Node.js 18+ and npm/yarn
- Android Studio (for Android portfolio builds)
- Git

### Installation

```bash
# Clone the repository
git clone [https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-36.git](https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-36.git)

# Navigate to project directory
cd moekyawaung-developer-portfolio-36

# Install dependencies
npm install

# Start development server
npm run dev
```
## Build for Production
```
# Build optimized production bundle
npm run build

# Start production server
npm start
```
